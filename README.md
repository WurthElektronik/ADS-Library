`ADS Libraries for Würth Elektronik Products`
=========
## Introduction
Welcome to Würth Elektronik ADS Library repository. <br>
The libraries are created and maintained by Würth Elektronik EDA Team, for any questions and suggestions please feel free to contact EDA team by email: <libraries@we-online.com>

## Library Component Coverage
* RF Antennas <br>
_WE-MCA_

* Balun <br>
_WE-BAL_

* CM Chokes for Data Lines <br>
_WE-CCMF, WE-CNSW-HF_

* CM Chokes for Power Lines <br>
_WE-CMBH, WE-CMBNC, WE-FC, WE-FCLP, WE-LF, WE-LF-SMD, WE-LPCC, WE-TFC, WE-TPB, WE-TPBHV_

* Ferrites for PCB Assembly <br>
_WE-MPSA, WE-MPSB_

* Power Inductors <br>
_WE-DPC, WE-MCRI, WE-TDC, WE-TDCHV_

* RF Inductors <br>
_WE-ACHC, WE-CAIR, WE-KI, WE-KIHC, WE-MK, WE-RFH, WE-RFI, WE-TCI_

* Signal Filters <br>
_WE-BPF, WE-LPF_
